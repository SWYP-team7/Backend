## 깊은 대화로 이끌어주는 대화 주제 주천 앱 - 담담

## 주요 기능
- 회원 가입 / 로그인 (JWT 기반 인증)
- 카카오 OAuth 로그인
- OpenAI API를 이용한 키워드 기반 대화 생성 및 리포트 생성

## 기술 스택
- Java 21 / Spring Boot 3.4.5 
- Gradle
- MySQL
- JPA
- GitHub Actions (CI/CD)
- AWS EC2
- Nginx
- Docker, Docker Hub
